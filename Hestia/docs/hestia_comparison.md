# HESTIA論文との比較

## 前提

比較対象はリポジトリ内のプレプリント「HESTIA: A Home Environment Simulator Targeting Inhabitant Activities」v2（2025-02-12）です。本実装は論文の概念と外部仕様を参考にした独立再実装で、公式HESTIAのソース、設定、内部API、Tuya出力との互換性はありません。

## 対応

| 論文から読み取れる機能 | 本実装 |
|---|---|
| PythonとCLIによるシミュレーション | `smart-home-sim`の非対話CLI |
| SimPyによる離散イベント実行 | 住人ごとのSimPyプロセス |
| 部屋、屋外空間、最大収容人数 | Room Resourceと移動中状態 |
| 重み付き住宅グラフと経路探索 | NetworkX最短経路。論文のA*とアルゴリズムは異なるが外部挙動に対応 |
| 活動名、時間、変動率、場所、ADL | ActivityConfigで対応 |
| 長時間活動中の関連活動と復帰 | ブロック単位抽選、副次活動後に主活動室へ復帰 |
| 関連活動中の主デバイス保持/停止 | `preserve_primary_devices`で選択 |
| 複数住人、初期位置、優先度、好み、週間ルーティン | ResidentConfigと共有デバイス調停 |
| 活動終了後のデバイス状態復元 | 最初の利用前状態・属性を保存し、最後の利用終了時に復元 |
| 照明、在室、プラグ、コーヒー、空調、テレビ | 対応デバイスとして実装 |
| 単純状態と複合属性 | 主状態と属性JSONを同時記録 |
| CSVによる合成データ出力 | 完全・簡易・状態ベクトルCSV |

## 独自拡張

- JSON/YAMLとPydanticの厳格な相互参照検証
- ContactSensorとエッジDoorSensor、ドア競合のResource直列化
- 操作主体と全室在室者を分離した正解情報
- 状態ベクトルとAruba/CASAS風ログ、活動START/END境界
- 単一seed、安定順序、ディレクトリSHA-256によるバイト再現性
- 共有デバイス停止抑制と、同優先度時の住人ID辞書順規則
- 生成直後の時刻、必須値、ドア、容量、活動場所検査
- 物理部屋内の論理ゾーン、zone Motion、zone→物理部屋カテゴリ統合
- 複数の重み付きADL内マイクロ行動テンプレートと内部監査トレース
- 5種類の分布、予定時刻jitter、間隔、省略確率、平日・休日差
- 副次活動の時間窓、クールダウン、回数上限、非復帰
- stress限定の真値／観測分離型センサー不完全性

## 未対応

- 論文が扱うTuya準拠メッセージ形式と実機メーカー別属性
- 周期的なreportメッセージ、電流などのテレメトリ、任意頻度の自動報告
- 論文で列挙されるsound system
- 論文と同一の14日・4機器・Mann-Whitney U検定（本監査は7日の記述統計・分布比較）
- 物理回路・検知範囲に基づく実センサーノイズ（stressの故障profileは独自の耐性評価モデル）
- 好みからの活動自動生成、3D可視化（部屋・デバイス・人物を編集する2DのHestia Studioは提供）
- 論文の設定形式・クラス・Tuyaプロトコルとのドロップイン互換

## 論文から判断不能

- seed固定時に全出力がバイト一致するか
- 同優先度住人の厳密なタイブレーク規則
- ドアをほぼ同時通過する場合の競合制御と状態順序
- タイムゾーン、夏時間、マイクロ秒丸めの規則
- 活動境界を外部ログへ保存する厳密な形式
- 原著の全設定エラーに対する診断粒度

## 解釈上の注意

論文は部屋間探索にA*を説明しています。本実装は座標ヒューリスティックをシナリオに要求せず、移動時間を重みにしたNetworkXの最短経路を使用します。したがって目的は対応しますが、内部方式は意図的に同一化していません。また、論文の「industry compliant」出力はTuya系メッセージを指し、本実装の完全イベントCSVは研究向けの独自正規形式です。

論文が、ルーティンと関連活動の粒度が低い場合は変化・相互作用が限定されると述べる点を、
本拡張は詳細なopt-inシナリオで補います。これは公開された論文上の機能要件から独自設計した
もので、原著ソースの複製・翻訳・内部形式の再現ではありません。

既存監査は[`reports/semantic_audit.md`](../reports/semantic_audit.md)、改善後のAruba集計比較は
[`reports/functional_vs_realistic_vs_aruba.md`](../reports/functional_vs_realistic_vs_aruba.md)を
参照してください。
