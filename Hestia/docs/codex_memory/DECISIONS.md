# 維持する設計判断

用途: 再検討を避けるための理由・互換性境界。基本制約と必須検査はrootの`AGENTS.md`を正とし、ここには複製しない。

- **既存シナリオの乱数消費を維持**: 文字列routine・ゾーンなし・旧副次活動はlegacy分岐を通す。追加機能を使わない入力に新しい抽選や出力を加えない。同seed保証の条件と基準ハッシュは[再現性](../reproducibility.md)。
- **決定的な経路・調停**: NetworkXの重み付き最短経路を使い、同距離はID列辞書順。座標ヒューリスティックを持たないため論文のA*を再現しない。共有機器の勝者は`(-priority, resident_id)`で一意化する。
- **共有機器は利用前状態へ復元**: 最初の利用前に状態・属性を保存し、最後の利用終了時だけ復元。常にOFFへ戻す旧方式は初期ON・属性を破壊するため不可。詳細: [意味論監査の修正1](../../reports/semantic_audit.md)。
- **ドアと部屋容量の取得順序**: ドア別ResourceでOPEN→退出→移動→CLOSEを直列化し、その後に到着部屋容量を取得。OPEN重複と容量1部屋間の循環待ちを防ぐ。詳細: [空間設計](../architecture.md)。
- **ADLと真値を保護**: microの内部ラベルは別トレースへ分離し親ADL境界を増やさない。在室正解はzone modeでも物理部屋単位。完全意味検証は真値に適用し、stressの観測ノイズとの一致を要求しない。詳細: [アーキテクチャ](../architecture.md)。
- **CASAS互換を別presetで提供**: 既存`legacy`を維持し、研究parser向けは`motion-door` / `all-devices`（センサー4列、ADL境界6列・begin/end）。旧5列だけではADL区間を読めない。詳細: [出力形式](../output_formats.md)。
- **Studioは共通モデルの薄い入口**: `editor_layout`は表示専用で出力・乱数に影響させない。保存・実行・extendsのパス境界、検証済み設定の反映、実行先の非上書きを維持。詳細: [Studio設計](../architecture.md)。
- **校正は意味的妥当性を優先**: 生Aruba系列のコピーや無意味な反転で密度を稼がず設定だけを校正。既存比較条件はK=15 / h=0 / 1秒保持 / 5秒OFF遅延。合成データをAruba代替・統計的等価と主張しない。選定理由: [校正方法](../calibration_method.md)、利用範囲: [研究利用](../research_usage.md)。
