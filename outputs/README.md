# Outputs

将来の統合出力先です。生成物の管理方針は `docs/artifact_policy.md` を参照してください。

- `reproducible/`: 論文・発表の再現に必要な固定成果物だけを置く。
- `tmp/`: 試行中の一時出力を置く。中身はGit管理しない。
- `logs/`: 実行ログを置く。中身はGit管理しない。

現在のコードは互換性維持のため、まだ以下の既存ディレクトリへ出力します。

- `state/`: 代表状態テーブル
- `picture/`: 状態遷移図、タイムライン図、LLM入力JSON
- `output/`: ベースライン、LLM出力、評価結果

既存結果を壊さないため、今回の整理では生成済みファイルを移動していません。
