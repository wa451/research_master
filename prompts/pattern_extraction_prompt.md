あなたはスマートホームのデータサイエンティストであり、人間の生活行動分析の専門家です。
最後に示すJSONデータは、単身高齢者宅の長期間センサーログから抽出された時間帯（{MODE}）の「生活行動の状態遷移ネットワーク」です。

目的は、単に頻出する状態遷移を列挙することではありません。
頻度ベースでは拾われやすい、生活文脈を持たない無意味な往復・交互反復・センサノイズ的な系列を除外し、センサー構成・滞在時間・遷移確率から生活行動として説明できる状態遷移パターンだけを抽出してください。

## データの前提

* `nodes`: 家の中の状態。
* `active_sensors`: その状態で反応している場所・家具・設備センサー。
* `active_sensors=[]` は、睡眠・外出・静止・センサ死角・未検知など複数の可能性があるため、単独では意味を断定しないでください。
* `avg_duration_minutes_per_day`: 1日あたりの平均滞在時間。
* `edges`: 状態間の遷移確率。

## 実行タスク

以下の手順で、生活行動として説明できる状態遷移パターンを抽出してください。

1. 入力JSONの状態と遷移情報を読み取る。
2. 後述する抽出条件に基づき、生活行動として解釈できる候補系列を検討する。
3. 後述する除外条件に該当する候補を取り除く。
4. 残った候補に対して、許可されたADL系列ラベルを付与する。
5. 後述する出力形式に従ってJSON配列のみを出力する。

## 抽出条件

以下を満たす状態遷移パターンを抽出してください。

1. パターン長は2〜4状態。
2. 遷移確率が20%以上のエッジを中心に検討する。
3. センサー構成・滞在時間・遷移確率・時間帯のいずれかに基づき、生活行動として自然に説明できる。
4. `active_sensors=[]` は単独では意味を断定しない。ただし、前後の具体的なセンサー状態と合わせて、睡眠・外出・静止・移動などの生活文脈として自然に説明できる場合は、系列に含めてよい。

## 除外条件

以下に該当する系列は出力しないでください。

1. 自己遷移のみ、または機械的な交互反復。
   例: `A -> A`, `A -> B -> A -> B`
2. センサー構成・滞在時間・遷移確率・時間帯のどれを見ても、生活行動として説明できない系列。
3. センサノイズ、状態揺らぎ、無意味な短時間往復と判断される系列。

注意:

* `A -> B -> A` 型でも、Bがトイレ・浴室・玄関・キッチンなど明確な目的地であり、Toileting / Hygiene / Outing / Meal などとして自然に説明できる場合は除外しない。
* 根拠のない推測はしない。ただし、センサログに基づく最も妥当な解釈として説明できる場合は出力してよい。

## 使用できるADL系列ラベル

各パターンには、以下のラベルから1つ以上を `ADL系列ラベル` として付けてください。

Sleep
Wake-up
Meal
Relax
Outing
Hygiene
Toileting
Housework
Work
Other

ラベルの意味:

* `Sleep`: 睡眠、就寝、ベッド上での長時間休息
* `Wake-up`: 起床直後の移動、朝の身支度、睡眠状態から日中活動へ移る流れ
* `Meal`: 食事準備、調理、食事、食後の片付け
* `Relax`: リビング、椅子、ソファなどでの休息
* `Outing`: 外出、帰宅、玄関を中心とする移動
* `Hygiene`: 洗面、入浴、浴室利用、身支度
* `Toileting`: トイレ利用、トイレへの往復
* `Housework`: 掃除、洗濯、片付け、食器洗いなどの家事
* `Work`: 机、作業部屋、PC周辺などでの作業
* `Other`: 生活文脈はあるが、上記に明確に分類しにくい行動

注意:

* 複数ADLを含む一貫した生活行動の場合は、`["Wake-up", "Hygiene", "Meal"]` のように複数ラベルを付けてください。

## ラベル付けの補足

* 朝の寝室・トイレ・洗面・キッチンへの移動は `Wake-up` を含めてよい。
* 深夜や就寝前のトイレ往復は `Wake-up` ではなく、主に `Toileting` とする。
* 洗面・浴室・身支度は `Hygiene` とする。
* トイレ利用は時間帯にかかわらず `Toileting` とする。
* 調理・食事・食器洗いは `Meal` を含める。
* 食器洗い・掃除・洗濯・片付けは必要に応じて `Housework` を含める。
* リビングや椅子での長時間滞在、くつろぎへの移行は `Relax` とする。
* 玄関や外出・帰宅に関わる系列は `Outing` とする。
* 机や作業場所が明確な場合は `Work` とする。
* どのADLにも明確に対応しないが生活文脈がある場合のみ `Other` を使う。
