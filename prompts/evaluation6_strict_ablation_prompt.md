## タスク

以下をすべて満たすパターンだけを抽出してください。

1. `state_sequence` は2〜4状態であること。
2. 入力representationから確認できる遷移または時系列上の連続状態列であること。
3. 状態定義、時間帯、および入力representationで確認できる関係から、生活行動として自然に説明できること。
4. 自己遷移だけ、機械的な交互反復、または根拠のない推測は除外すること。
5. 同じ時間帯に同じ `state_sequence` を重複して出力しないこと。

## 使用できるADL系列ラベル

各パターンに、以下から1つ以上の `adl_sequence` を付けてください。

* `Sleep`: 睡眠、就寝、ベッド上での長時間休息
* `Wake-up`: 起床直後の移動、朝の身支度、睡眠状態から日中活動への移行
* `Meal`: 食事準備、調理、食事、食後の片付け
* `Relax`: リビング、椅子、ソファなどでの休息
* `Outing`: 外出、帰宅、玄関を中心とする移動
* `Hygiene`: 洗面、入浴、浴室利用、身支度
* `Toileting`: トイレ利用、トイレへの往復
* `Housework`: 掃除、洗濯、片付け、食器洗いなどの家事
* `Work`: 机、作業部屋、PC周辺などでの作業
* `Other`: 生活文脈はあるが、上記に明確に分類しにくい行動

複数ADLを含む一貫した行動の場合は複数ラベルを付けて構いません。根拠が弱い場合は出力しないでください。

## 出力形式

JSON配列だけを出力してください。Markdown、説明文、コードブロックを付けてはいけません。各要素は次の5キーをすべて持ち、他のキーを持ってはいけません。

```json
{
  "time_band": "{TIME_BAND}",
  "pattern_name": "パターン名",
  "adl_sequence": ["Meal"],
  "rationale": "入力で確認できる根拠",
  "state_sequence": ["状態1", "状態2"]
}
```

`time_band` は必ず `{TIME_BAND}`、`adl_sequence` と `state_sequence` は文字列配列にしてください。抽出すべきパターンがない場合は `[]` を出力してください。
